## ✨ Overview

**SmartShop** is a modern front-end e-commerce website designed to provide a smooth and engaging online shopping experience.

The project focuses on clean UI design, responsive layouts and practical JavaScript functionality such as product filtering, search, sorting, wishlist management, shopping cart operations and checkout.

## 🎯 Key Features

| Feature | Description |
|---|---|
| 🛍️ Product Catalog | Browse products across multiple categories |
| 🔎 Search | Search products instantly by name |
| 🗂️ Categories | Filter products by category |
| ↕️ Sorting | Sort by price and rating |
| ❤️ Wishlist | Save favorite products |
| 🛒 Shopping Cart | Add, remove and update products |
| 💾 LocalStorage | Preserve cart and wishlist data |
| 🎟️ Coupon | Apply discount code `SMART10` |
| 🌙 Dark Mode | Switch between light and dark themes |
| 👀 Quick View | View product details without leaving the page |
| 💳 Checkout | Interactive checkout form |
| ⏱️ Deal Timer | Limited-time offer countdown |
| 🔔 Notifications | User-friendly toast notifications |
| 📱 Responsive | Works across desktop, tablet and mobile |
